# SOP Quality Checklist

Use this checklist before considering an SOP ready.

## Human Side

- [ ] The human knows what to prepare before starting.
- [ ] Required accounts, permissions, and paths are named.
- [ ] Privacy-sensitive choices are explicit.
- [ ] The human knows what to do after the AI finishes.

## AI Side

- [ ] The AI has a clear execution order.
- [ ] The AI knows which files to create or update.
- [ ] The AI knows what not to touch.
- [ ] The AI has concrete verification steps.
- [ ] The AI can recover from common failure modes.

## Artifact Quality

- [ ] The final directory structure is shown.
- [ ] Important config files are described.
- [ ] Example prompts are included.
- [ ] The SOP is not dependent on hidden chat history.
- [ ] The SOP can be reused by another person.

## Verification

- [ ] There is a final state checklist.
- [ ] There are commands or manual checks where useful.
- [ ] The expected result is described in plain language.
